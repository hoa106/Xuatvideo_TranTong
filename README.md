# Xuatvideo_TranTong

Xuất MP4 hàng loạt **thẳng từ project CapCut PC** — không cần mở CapCut, nhanh hơn nút Export.

## Tải về
👉 **[Tải bản mới nhất](https://github.com/hoa106/Xuatvideo_TranTong/releases/latest/download/Xuatvideo_TranTong.zip)** (giải nén rồi bấm đúp `Xuatvideo_TranTong.exe`)

## Dùng
1. Lần đầu mở, tool tự tải ffmpeg (~200 MB, chỉ một lần) — chờ thanh tiến độ chạy xong.
2. Tool tự liệt kê các project CapCut trên máy. Project nằm chỗ khác → bấm **📁 Thư mục quét**.
3. Tích các video cần xuất → chọn **1080p** hoặc **4K** → bấm **▶ Xuất lần lượt**. Xong cả danh sách sẽ có chuông báo.

Mỗi dòng có nút **📁 Chọn…** để đổi nơi lưu, **👁 Xem** để soát video trước khi xuất.
Cột **Đã xuất?** tự tìm file MP4 đã xuất trên máy (✓ xanh). Nhãn **⚡ Tool** = tool xuất y nguyên; **🎬 CapCut** = project dùng hiệu ứng riêng của CapCut → hãy xuất bằng CapCut.

## Yêu cầu
- Windows 10 / 11, trình duyệt Microsoft Edge (có sẵn).
- Card NVIDIA giúp xuất nhanh hơn nhiều (không có vẫn chạy bằng CPU).

> Windows có thể hiện "Windows protected your PC" vì tool chưa ký số → bấm **More info → Run anyway**.
