# Xuatvideo_TranTong

Tự **điều khiển CapCut PC xuất MP4 hàng loạt** — tích các video, bấm một nút, tool tự mở CapCut, bấm Xuất từng project rồi tắt CapCut.
File MP4 là **file CapCut thật** (giống hệt bấm Export bằng tay).

## Tải về
👉 **[Tải bản mới nhất](https://github.com/hoa106/Xuatvideo_TranTong/releases/latest/download/Xuatvideo_TranTong.zip)** (giải nén rồi bấm đúp `Xuatvideo_TranTong.exe`, đọc kèm `HUONG DAN.txt`)

## Dùng
1. Tool tự liệt kê các project CapCut trên máy (video đã xuất tự ẩn). Project nằm chỗ khác → bấm **📁 Nơi tìm project**.
2. Chọn độ phân giải **720p / 1080p / 2K / 4K**.
3. Tích các video cần xuất (hoặc **☑ Tích tất cả**) → bấm **▶ Xuất lần lượt**. Xong cả danh sách sẽ có chuông báo.

Khoảng 30 giây đầu mỗi video (lúc tool mở project trong CapCut) **đừng động vào chuột / bàn phím**. Lúc CapCut đang xuất thì dùng máy bình thường, chỉ đừng thu nhỏ cửa sổ CapCut.

## Yêu cầu
- Windows 10 / 11, trình duyệt Microsoft Edge (có sẵn), **CapCut PC** đã cài.
- CapCut để **tiếng Việt**, màn hình chính dạng **bảng** (cột "Chỉnh sửa gần nhất"), Windows Scale **100 %**.
- Project dùng tính năng Pro thì tài khoản CapCut cần có Pro (tool không lách).

> Windows có thể hiện "Windows protected your PC" vì tool chưa ký số → bấm **More info → Run anyway**.
